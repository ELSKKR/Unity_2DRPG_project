## 1. Canvas 是 640×360，不是 960×540

`Persistent.unity` 的 `[Canvas]` 是書本 UI 那邊定的 **640×360、比例鎖高度**——
1080p 下剛好 **3 倍整數縮放**。`TitleScreen.unity` 的 `[TitleCanvas]` 跟著改成一樣的值，
這樣標題畫面和遊戲內的像素粗細才會一致。

```
1080 ÷ 360 = 3   →   素材 1 像素 = 畫面 3 像素，剛好整數
```

圖集的 `spritePixelsToUnits` 是 100（跟 `referencePixelsPerUnit` 一致），
所以 **1 素材像素 = 1 個 UI 單位**，排版時填的數字就是素材像素數。

**這裡量體裁衣，不要用「960×540 的數字乘 2/3」去換算**：素材本身的九宮格邊界是
固定像素值，畫面能用的寬度變小了，該縮的是「你自己選的自由尺寸」（面板寬度、
按鈕寬度這種），不是素材的邊界。

## 2. 圖集切片：兩份工作合併之後的規則

圖集在另一條線上也被動過（見系統 11），兩邊的切片**已經合併成一份**：

- **133 個切片全部有語意化命名**（`Panel`、`Button`、`Bubble`……），沿用之前那份的取名。
- **九宮格邊界的來源分兩種**：
  - 4 張已經在 `DialogPanel` / `ChoicePanel` 裡實際跑起來的（`Panel_Square`、`Plate`、
    `Button`、`Button_Pressed`）——邊界維持**系統 11 那邊量出來的值**，這份文件不覆蓋。
  - 其餘 43 張——邊界是**逐像素掃描算出來的最大可拉伸邊界**（演算法：從四邊往內掃，
    找出最大的一組邊界，使中間各列/行與正中央那列/行完全相同），133/133 在原始尺寸下
    驗證過逐像素還原。

  > 系統 11 那邊對其餘 16 張沒實際用到的素材（`Bubble`、`Panel_Small`、`Panel`、
  > 各種 `Button_*` 尺寸……）也批次填過邊界，但那批像是同一家族套同一組數字
  > （所有面板都填 `6,6,6,5`、所有按鈕都填 `2,4,2,2`），不是逐張量的。實測 `Bubble`
  > 若照那組數字拉伸，右下角的摺角裝飾會被拉伸变形（那個折角實際需要 16 像素的
  > 右邊界，不是 8）。所以這份文件用的是逐張量出來的版本，**只有那 4 張真正在跑的例外**。

- **`internalID` 沒有動過**，改名和改邊界不會讓既有引用斷掉。

本文件用到的幾張：

## 4. 字級（640×360 canvas）

| 用途 | 大小 | 換算 |
|---|---|---|
| 標題 | 38 | ≈ 55px（1080p） |
| 面板標題 | 18 | ≈ 26px |
| 按鈕 | 13 | ≈ 19px |
| 內文 | 12 | ≈ 17px |
| 次要資訊 | 10 | ≈ 14px |

公式：`畫面像素 ≈ 字級 × (52.1 ÷ 90) × 3`（52.1/90 是 Silver 字框高與 pointSize 的比、
3 是這個 canvas 在 1080p 下的縮放倍率）。

## 5. ⚠️ 動 UI 文字之前一定要看這段

字型是「Silver 主字型 + Cubic 備援」，字元事先烘進資產（見系統 9）。
用到沒烘過的字，編輯器裡正常、打包版會缺字或高低不齊。檢查腳本：

```bash
python3 Tools/check_baked_chars.py       # 有缺字就 exit 1
python3 Tools/check_baked_chars.py -v    # 連缺字出現在哪個檔案都列出來
```

目前已烘 **636** 個字元（比之前多，書本 UI 那條線又烘了一批）。
這次的重建（標題/存檔槽/互動提示/通知/裂隙過場）**沒有增加任何新缺字**。

剩下 8 個缺字，全部不在這份文件管的範圍內（`InventorySlot` 等 prefab 的佔位文字、
`RiftZone.cs`/`SavePoint.cs` 的訊息字串），列在這裡供之後參考：

```
具名度暫異稱道項
```

## 6. 新增/沿用的程式

### `Assets/Scripts/UI/MenuChevrons.cs`

選中按鈕左右的箭頭，跟著滑鼠/鍵盤選取移動。每幀輪詢而不是掛事件——
一頁最多六顆按鈕，成本可忽略，換來的是不用在每顆按鈕上多接一份線。

### `Assets/Scripts/UI/SaveSlotEntryUI.cs`

存檔槽格子拆成兩個欄位：`label`（場景＋時間）、`metaLabel`（遊玩時間）。
槽號由格子左邊的徽章顯示，文字不再重複「存檔槽 N」。`metaLabel` 留空會退回舊的單欄位行為。

### 按鈕的 hover / pressed

不寫程式，全部靠 Unity 內建的 `Transition: SpriteSwap`，
Highlighted/Pressed/Selected 都指向 `Button_Pressed`。
