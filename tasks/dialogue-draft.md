# 對白稿：森林留客（第四版）

> **版本紀錄**
> - 第二版：修正「講了情報內容卻沒給情報」，補完亞爾追魯克的動機。
> - 第三版：魯克改成由玩家當中間人；需要情報才出現的選項，條件一律來自另一個 NPC。
> - **第四版（2026-09-25，使用者審）**：
>   - 情報內容不能互相重複（規則 4）。
>   - 同一段對話裡的選項，要對得上這段的開場（規則 5）。
>   - 做過就不該再問的選項要隱藏（規則 6，新增欄位 `hideIfEventID`）。
>   - 配合使用者移動 NPC：亞爾在屋外的椅子前、妮娜在 C 屋門外。

## 零、規則

1. **資訊守恆**：一句台詞講出的事實，必須包含在「這次選擇會解鎖的情報」裡。否則只能講以下幾種東西：
   - 玩家自己看得到的（誰住哪裡、誰站在哪裡）
   - 玩家自己經歷過的
   - 任務說明已經記錄的
   - 純氣氛（不會被任何劇情用到的細節）
   - 指路（例如「去問誰」，但不說內容）
2. **條件一致**：要先有某筆情報才會出現的選項，措辭要跟那筆情報的來源、內容一致。例如「聽愛拉說……」就只能是愛拉給的情報。
3. **一個選項最多給一筆情報**（`grantsIntel` 只有一個欄位）。講的內容超出那筆情報，就拆成兩個選項。
4. **情報不重複**：一個事實只屬於一筆情報。其他情報需要用到它時，就讓玩家自己把兩筆情報連起來推論，不重寫一次。唯一例外是「揭露」本身：`yaer_that_night` 要推翻 `yaer_temper` 裡「亞爾是一個人進林子」的誤會，所以一定會提到同一個晚上。
5. **選項要對得上開場**：同一段對話換了開場，選項也要跟著換，不能回答一個這段沒有問的問題。後面的 chat 仍然要帶著前面那幾筆情報的選項（否則沒問過的玩家永遠拿不到），只是措辭要改成符合新的開場。
6. **做過就隱藏**：像帶話這種做過一次就不該再問的選項，用 `hideIfEventID` 在對應旗標成立後隱藏。如果隱藏後這段只剩下「（離開）」，就連「（離開）」一起隱藏，讓對話直接結束。

標示：
- **〔改〕** 改寫
- **〔新〕** 新增
- **〔留〕** 原樣
- `→` 後接選了之後的反應台詞
- `［情報：x］` 表示選了會解鎖情報 x
- `［旗標：x］` 表示選了會標記旗標 x
- `〈需要：x〉` 表示要先有情報 x，這個選項才會出現

## 一、世界觀補完（寫進台詞前先對齊）

- **森林的兩層規則**
  - 往**外**走的人，走著走著會回到村裡。森林不害人，只是不放人走。等村子捨不得你了，路就會開。
  - 夜裡**北邊林子深處**會出現一點一點的光，像有人提燈在走。光不是路，跟過去的人會被「撞」回來。阿茉的阿嬤那一輩的人都說：看到了也別跟。光到底是什麼，**不揭曉**，保留神祕感。
- **魯克**：三年前摸進村子，想偷賽勒屋裡的藥材去賣，被當時還是護衛的亞爾當場逮到。之後想溜，森林不放他走。從此他守在林道口等出路，村裡的事一概不管。
- **亞爾和魯克**：逮到魯克之後，亞爾三年來一直盯著他。魯克把亞爾當成看守自己的人，兩人互相看不順眼。
- **那一晚**：魯克困了三年、等不下去，決定往北邊林子深處走，想換個方向找出路。亞爾一直盯著他，發現後追了進去，把他推了出來，自己被撞倒，佩劍掉在林子裡。魯克頭也不回地跑了。
  - 魯克不知道自己撞上的是什麼，台詞裡也不提「光」。拿到 `forest_lights` 的玩家，可以自己把「北邊林子深處」和「看到光別跟過去」連起來（規則 4）。
- **為什麼沒人知道**：亞爾對誰都沒說他在追誰，因為護著魯克的名聲，是他身為護衛的本分。所以愛拉她們都以為亞爾是「一個人半夜進了北邊林子」。魯克也一直不敢說。
